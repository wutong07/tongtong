    生成在线浏览链接

    03 / PUBLISH

    点击发布后，模型会保存到你指定的公开 GitHub 仓库。链接接收者无需 Token，你关闭本页后链接仍然有效。模型任何获得链接的人都可以访问，请勿发布私密内容。

    Token 仅用于上传，并只保存在当前标签页，不会写入浏览链接。可在 GitHub 的 Settings → Developer settings → Fine-grained personal access tokens 创建，仓库权限选择 Contents: Read and write。
    单个文件不能超过 100 MB。
    发布内容会占用你的 GitHub 仓库存储空间。

    打开

    模型已持久保存在 GitHub，关闭或刷新本页不会影响其他访问者。

    第一次使用？查看部署与发布说明
    1. 把本文件命名为 index.html 并上传到一个公开 GitHub 仓库，在仓库 Settings → Pages 中选择从 main 分支根目录部署。
    2. 打开 GitHub Pages 地址，选择模型及配套文件并确认预览。发布的仓库可以使用当前仓库，也可以使用另一个公开仓库。
    3. 创建仅拥有目标仓库 Contents 读写权限的 Fine-grained Token，填入后点击“上传并生成浏览链接”。
    4. 复制生成的新链接分享给他人。浏览链接只需公开读取模型，访问者不需要登录 GitHub。
